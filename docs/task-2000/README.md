# TASK-2000: готовность ко второй главе

TASK-2000 переводит проекты из старой первой главы в новый формат. Этот репозиторий уже прошёл новые TASK-1005/1006, поэтому основные слои соответствовали требованиям до начала работы. Ветка содержит оставшиеся изменения и результаты сверки.

## Изменения

- JSON/query Bind возвращают bindingError непосредственно; статус 400 доступен и при вызове через интерфейс Binding. Публичные функции делегируют вызов без повторного оборачивания.
- Ошибки чтения JSON имеют сообщение `incorrect parameters`, отсутствующий запрос/тело — `invalid request`, ошибки валидации сохраняют текст валидатора.
- Добавлены проверки реализации интерфейса Binding на этапе компиляции и тесты точных сообщений и статуса прямого Bind.
- Загрузка конфигурации сообщает об отсутствии .env и продолжает читать окружение; ошибка envconfig имеет контекст `Failed to load config`.
- Стандартный log сообщает о подключении PostgreSQL и перечисляет зарегистрированные маршруты при старте.
- Убраны выполненные TODO из секций конфигурации, health-check и регистрации маршрутов.

## Сверка остальных требований

| Требование | Результат |
|---|---|
| Go 1.25, отсутствие zerolog | Уже выполнено; go mod tidy не изменяет зависимости |
| config.Load() без возврата, config.Root | Уже выполнено |
| Таймауты PostgreSQL time.Duration, 30s | Уже выполнено |
| AppError, HTTPStatus, общий HandleError | Уже выполнено |
| httph: response.go и decode.go | Два рабочих файла; существующий response_test.go сохранён |
| Раздельные Request/Response DTO, binding-теги | Уже выполнено |
| Цена int64 / BIGINT | Подтверждено в коде, миграции и работающей базе |
| GetByGUIDs, фильтры List | Уже выполнено |
| NewClient, NewHTTP и wiring | Уже выполнено |
| POST для списков, отсутствие точечных GET | Проверено; восемь API-маршрутов плюс GET /health |

Сброс PostgreSQL не нужен: колонка product.price уже bigint. Сохранены существующие проверки пустых UUID/пакетов GUID, частичный PATCH категории, закрытие подключения при ошибках и корректное вычисление версии миграций. Переписывание этих работающих частей под буквальный текст примеров не требуется для совместимости со второй главой.
